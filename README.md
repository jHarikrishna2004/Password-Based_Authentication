Password Strength Checker Web App

This is a Flask-based web application that checks password strength and 
provides secure access control. The system evaluates passwords as weak, 
medium, or strong using backend Python logic and redirects users accordingly
to a protected About page.It is built using HTML, CSS, and python, and demonstrates
how basic authentication logic works in web applications. It can also be upgraded 
with backend services like Firebase Authentication for real-world usage.

Features
- Password strength validation (Weak / Medium / Strong)
- Access control to protected page
- Modern responsive UI design
- Instant feedback for user input
- Easily upgradable to Firebase authentication
- Backend logic using Python (Flask)
- Clean and simple UI using HTML templates
- Modular project structure


Technologies Stack
- Python 
- Flask 
- HTML5
- CSS 
- Firebase Authentication
